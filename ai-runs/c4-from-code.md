Припущення: межа системи охоплює API поштомата, SMS-обробник і нічну задачу повернення посилок. У контекстній діаграмі показані зовнішні користувачі та системи, які згадані в коді або документації. У діаграмі контейнерів PostgreSQL позначено як продакшн-сховище за документацією: у наданій копії `src/db.js` використовує сховище в пам’яті.

### System Context

```mermaid
C4Context
    title Контекст системи «Поштомат громади»

    Person(resident, "Мешканець", "Отримує SMS-код і забирає посилку")
    Person(staff, "Персонал", "Переглядає список посилок")
    System_Ext(courier, "Служба доставки", "Реєструє посилки сканером і надає API повернення")
    System_Ext(sms, "SMS-провайдер", "Надсилає мешканцям SMS")
    System_Ext(monitoring, "Система моніторингу", "Перевіряє стан сервісу")

    System(locker, "Поштомат громади", "Приймає посилки, надсилає коди отримання та обробляє видачу й повернення")

    Rel(resident, locker, "Вводить код отримання через екран поштомата")
    Rel(staff, locker, "Переглядає посилки")
    Rel(courier, locker, "Реєструє посилку та запитує повернення неполучених посилок")
    Rel(locker, sms, "Надсилає SMS із кодом отримання")
    Rel(monitoring, locker, "Перевіряє стан через health API")
```

### Container

```mermaid
C4Container
    title Контейнери системи «Поштомат громади»

    Person(resident, "Мешканець")
    Person(staff, "Персонал")
    System_Ext(courier, "Служба доставки", "Сканер і API повернення")
    System_Ext(sms, "SMS-провайдер", "HTTP API")
    System_Ext(monitoring, "Система моніторингу", "Перевіряє health API")
    System_Ext(cron, "Cron на VM", "Запускає нічну задачу")

    System_Boundary(locker, "Поштомат громади") {
        Container(api, "HTTP API", "Node.js", "Реєстрація посилок, видача за кодом, список для персоналу та health endpoint")
        Container(worker, "SMS-обробник", "Node.js", "Періодично знаходить посилки без сповіщення та надсилає SMS")
        Container(expiry, "Нічна задача повернення", "Node.js", "Знаходить посилки старші за 72 години, позначає їх поверненими та запитує повернення")
        ContainerDb(db, "Сховище посилок", "PostgreSQL у продакшні", "Посилки, події та сесії персоналу")
    }

    Rel(resident, api, "Вводить код отримання", "HTTPS / POST /pickup")
    Rel(staff, api, "Переглядає посилки", "HTTPS / GET /admin/parcels")
    Rel(courier, api, "Реєструє посилку", "HTTPS / POST /parcels")
    Rel(monitoring, api, "Перевіряє стан", "HTTPS / GET /health")

    Rel(api, db, "Читає та змінює дані")
    Rel(worker, db, "Знаходить посилки без сповіщення та записує час SMS")
    Rel(worker, sms, "Надсилає SMS із кодом", "HTTP API")
    Rel(cron, expiry, "Запускає за розкладом")
    Rel(expiry, db, "Знаходить прострочені посилки та позначає повернення")
    Rel(expiry, courier, "Запитує повернення посилки", "HTTP API")
```

Документація в копії та реалізація різняться в деталях: код генерує шестизначний код і опитує чергу кожні 10 секунд; у документації вказані чотиризначний код і 30 секунд. Діаграми відображають структуру й інтеграції, а ці значення на них не деталізовано.
