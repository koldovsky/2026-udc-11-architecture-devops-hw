# Архітектура «Поштомата громади» у C4

**Джерело:** діаграми побудовані лише за [ARCHITECTURE.md](app/docs/ARCHITECTURE.md) (червень 2026, v1.5) і [README.md](app/README.md). Коду (`src/`, `bin/`, `deploy/`) у робочій директорії немає, тому звірити діаграми з реалізацією я не міг, а документ міг застаріти.

## Рівень 1: System Context

```mermaid
%%{init: {"c4": {"c4ShapeMargin": 110}}}%%
C4Context
  title Поштомат громади — System Context
  Person(resident, "Мешканець", "Забирає посилку за кодом з SMS")
  System_Ext(sms, "SMS-провайдер", "Доставляє SMS")
  Person(staff, "Персонал", "Переглядає список посилок")
  System_Ext(locker, "Екран поштомата", "Приймає код від мешканця")
  System(parcels, "Поштомат громади", "Реєструє посилки, надсилає коди отримання, перевіряє їх і позначає прострочені посилки як повернені")
  System_Ext(scanner, "Сканер служби доставки", "Зчитує посилки, що прибули")
  System_Ext(monitoring, "Моніторинг", "Стежить за доступністю сервісу")
  Rel(resident, locker, "Вводить код")
  Rel(sms, resident, "SMS з кодом")
  Rel(parcels, sms, "Замовляє SMS", "HTTP API")
  Rel(locker, parcels, "Надсилає код", "HTTP")
  Rel(scanner, parcels, "Реєструє посилку", "HTTP")
  Rel(staff, parcels, "Дивиться список посилок", "HTTP")
  Rel(monitoring, parcels, "Опитує стан", "HTTP")
  UpdateRelStyle(locker, parcels, $offsetX="-40", $offsetY="-45")
  UpdateRelStyle(scanner, parcels, $offsetX="-45", $offsetY="-45")
  UpdateRelStyle(sms, resident, $offsetX="-35", $offsetY="-25")
  UpdateLayoutConfig($c4ShapeInRow="3", $c4BoundaryInRow="1")
```

## Рівень 2: Container

```mermaid
%%{init: {"c4": {"c4ShapeMargin": 70}}}%%
C4Container
  title Поштомат громади — Container
  System_Ext(monitoring, "Моніторинг", "Стежить за доступністю")
  Person(staff, "Персонал", "Переглядає список посилок")
  System_Ext(scanner, "Сканер служби доставки", "Зчитує посилки, що прибули")
  System_Boundary(system, "Поштомат громади") {
    Container(expire, "Нічна задача", "Node.js", "Позначає посилки, старші за 72 години, як повернені")
    Container(api, "API", "Node.js, HTTP", "Реєструє посилки, перевіряє коди, віддає список персоналу та стан сервісу")
    Container(worker, "Worker", "Node.js", "Кожні 30 с шле SMS з 4-значним кодом для посилок без сповіщення")
    ContainerDb(db, "База даних", "PostgreSQL", "Посилки, події, сесії персоналу")
  }
  Boundary(outside, "Поза системою", "зовнішні учасники") {
    System_Ext(locker, "Екран поштомата", "Приймає код від мешканця")
    System_Ext(sms, "SMS-провайдер", "Доставляє SMS")
    Person(resident, "Мешканець", "Забирає посилку за кодом з SMS")
  }
  Rel(monitoring, api, "GET /health", "HTTP")
  Rel(staff, api, "GET /admin/parcels", "HTTP")
  Rel(scanner, api, "POST /parcels", "HTTP")
  Rel(locker, api, "POST /pickup", "HTTP")
  Rel(api, db, "Читає і пише")
  Rel(worker, db, "Бере посилки без сповіщення")
  Rel(expire, db, "Оновлює статус")
  Rel(worker, sms, "Надсилає SMS", "HTTP API")
  Rel(sms, resident, "SMS з кодом")
  Rel(resident, locker, "Вводить код")
  UpdateRelStyle(monitoring, api, $offsetX="-30", $offsetY="-55")
  UpdateRelStyle(staff, api, $offsetX="10", $offsetY="-65")
  UpdateRelStyle(scanner, api, $offsetX="30", $offsetY="-55")
  UpdateRelStyle(locker, api, $offsetX="-45", $offsetY="-40")
  UpdateRelStyle(worker, db, $offsetX="40", $offsetY="15")
  UpdateRelStyle(api, db, $offsetX="-5", $offsetY="-15")
  UpdateRelStyle(worker, sms, $offsetX="35", $offsetY="-40")
  UpdateRelStyle(sms, resident, $offsetX="35", $offsetY="10")
  UpdateLayoutConfig($c4ShapeInRow="3", $c4BoundaryInRow="1")
```

## Припущення

1. **Екран поштомата є зовнішньою системою.** У розгортанні є лише `api` і `worker`, а окремого коду екрана документи не згадують. Якщо екран розробляє ця ж команда, його треба перенести всередину межі системи як контейнер.
2. **Службу доставки представляє її сканер.** Документи описують виклик API саме зі сканера, тому окремого кур'єра на діаграмах немає.
3. **Нічна задача є окремим контейнером і працює з базою напряму.** Для неї немає API-ендпоінта, а в `docker compose` лише два сервіси. Спосіб запуску в документах не описаний, тому планувальника на діаграмі немає.
4. **Нічна задача написана на Node.js.** Я виснував це з розширення файлу `expire-parcels.js`.
5. **Персонал звертається до API напряму.** Адмінський інтерфейс ніде не згаданий.
6. **Назви й описи зовнішніх учасників частково мої.** Наприклад, «Зчитує посилки, що прибули» для сканера прямо в документах не сказано.

## Що варто знати, читаючи діаграми

- **Контейнер у C4 не дорівнює Docker-контейнеру.** PostgreSQL працює поза Docker, але на діаграмі це контейнер C4. Одна VM і `docker compose` належать до рівня Deployment, тому тут їх немає.
- **Рамка «Поза системою» не є елементом C4.** Вона потрібна лише для розкладки, щоб ці блоки опинилися під системою.
- **Схема в `ARCHITECTURE.md` неповна.** На ній немає персоналу, моніторингу й нічної задачі, хоча в списку компонентів вони є. Я додав їх на діаграми.

## Прогалини в документації

- **Вхід персоналу:** у базі є таблиця сесій персоналу, але ендпоінта входу серед описаних немає.
- **Відкриття комірки:** не сказано, як після `POST /pickup` відкривається комірка, тому цього зв'язку на діаграмах немає.
- **Драйвер PostgreSQL:** README каже, що залежностей немає, а сховище в репозиторії працює в пам'яті. Де живе реалізація для PostgreSQL, з цих документів незрозуміло.

## Перевірка рендера

Обидві діаграми рендеряться в Mermaid 12.2.0 без помилок. Контейнерну я переглянув на екрані шириною 1366 px, контекстну на 1366 і 1920 px: стрілки не проходять крізь блоки.

Розкладка контейнерної діаграми спирається на особливість перенесення рядків у Mermaid. В іншій версії або на вужчому екрані блоки можуть розташуватися інакше, але зміст діаграми не зміниться.

Для перевірки я тимчасово створював файли у scratchpad, поза проєктом, і вже їх видалив. У проєкті нічого не змінилося.
